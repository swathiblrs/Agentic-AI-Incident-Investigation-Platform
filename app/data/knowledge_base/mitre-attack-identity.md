source: MITRE ATT&CK Internal Notes
tags: T1078, T1110, T1556, valid-accounts, brute-force, mfa
---

Valid Accounts (T1078) covers adversary use of compromised credentials to bypass access controls.
Brute Force (T1110) includes password spraying, credential stuffing, and repeated authentication attempts.
Modify Authentication Process (T1556) includes MFA manipulation and persistence through identity workflows.

Analysts should correlate authentication events with device posture, user baseline, administrative changes,
cloud audit logs, and endpoint evidence before closing the alert.
